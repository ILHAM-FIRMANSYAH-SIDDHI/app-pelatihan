## Cara Menjalankan Proyek
1. Pindahkan folder proyek ke dalam direktori `htdocs` XAMPP (`C:\xampp\htdocs\app_pelatihan`).
2. Nyalakan layanan Apache dan MySQL di XAMPP Control Panel.
3. Buat database baru bernama `db_pelatihan` di phpMyAdmin dan sesuaikan konfigurasi pada file `db.php`.
4. Buka browser dan akses URL: `http://localhost/app_pelatihan/`
